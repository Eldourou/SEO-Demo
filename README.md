Εφαρμόστηκαν οι ακόλουθες Τεχνικές html-based seo 
1. Ονοματοδοσία Αρχείου
Το αρχείο να έχει περιγραφικό όνομα και να είναι στα αγγλικά.
2. Title Tag
Να υπάρχει μοναδικό <title> σε κάθε html, να περιγράφει σωστά το περιεχόμενο και να
περιέχει σχετική λέξη-κλειδί.
3. Meta Description
Να υπάρχει <meta name="description"> .
4. Responsive Σχεδίαση
Να υπάρχει σωστό <meta name="viewport"> και να προσαρμόζεται σε κινητό
5. Σωστή Δομή Επικεφαλίδων
ΜΟΝΟ ένα <h1>
Χρήση <h2> και <h3> όπου χρειάζεται
Σωστή ιεραρχία (όχι h3 πριν από h2)
6. Semantic HTML
Αντί για σκέτα <div> , να χρησιμοποιηθούν:
<header>
<nav>
<main>
<section>
<article>
<footer>
7. Εικόνες με Alt (περιγραφή εικόνας)
8. Καθαρά URL
Να αναφέρετε στο σχόλιο του αρχείου ποιο θα ήταν το ιδανικό URL.
9. Δήλωση Γλώσσας & Charset 
10. Canonical Tag (<link rel="canonical" href="https://www xxx.gr/" /> 	Υποδεικνύει την αυθεντική έκδοση της σελίδας
)
11. Αρχείο sitemap.xml
